# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Please do **not** report vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature for this repository. Include a clear description, affected version or commit, reproduction steps, impact, and any suggested mitigation. If private reporting is unavailable, contact the repository owner privately through GitHub.

We aim to acknowledge reports within 7 days and will coordinate disclosure and a fix with the reporter. Please do not publicly disclose the issue until a fix or coordinated disclosure plan is available.

## Scope

Reports are especially welcome for vulnerabilities that could expose scan data, bypass authorization safeguards, execute code, leak credentials, or cause scans to target unintended systems.
